# Warehouse Documentation

This folder contains the source files and supporting assets for the warehouse
documentation.

## Layout

- `render.R` is the user-facing script for rendering the full documentation,
  checking requirements, or rendering individual sections.
- `sections/_master.Rmd` is the internal master document used for the full
  documentation render.
- `sections/` contains the active child Rmd files included by the master
  document.
- `sections/fragments/` contains nested child Rmd fragments used by section
  files.
- `render_support/` contains internal helper scripts used by `render.R`.
- `docs/` contains supporting data files, images, Excel workbooks, CSVs, and
  helper scripts.
- `outputs/` contains the current standalone section PDFs generated by
  `render.R`.
- `old/` contains previous drafts and standalone source files that are not part
  of the current master render.
- `old/outputs_legacy/` contains older generated PDFs, HTML files, and DOCX
  outputs from previous render workflows.

## Render Workflow

Commands can be run from this folder, or from the repository root by using the
full path to `render.R`.

### Main Render Menu

Open `render.R` in RStudio and click **Source**. The script prints a numbered
menu in the Console pane. Type one option number, several section numbers
separated by commas, an actual section filename, or `full`.

The first options are:

- `1` renders the full documentation as `warehouse_documentation.pdf` in this
  root folder.
- `2` runs preliminary checks to find missing tools or packages. If something
  is missing, the script offers to install what it can.

Examples:

- `1` renders the full documentation.
- `2` runs preliminary checks.
- `3` renders the first listed section.
- `3,7` renders two sections.
- `topo.Rmd` renders the Topography section.

After a successful render, the created PDF opens automatically. Section PDFs
are written to `outputs/`.

### Render From Terminal

The same options work from a terminal opened in this folder:

```sh
Rscript render.R 1
Rscript render.R 2
Rscript render.R topo.Rmd
```

From the repository root, use the script path:

```sh
Rscript documentation/warehouse_documentation/render.R 1
Rscript documentation/warehouse_documentation/render.R 2
Rscript documentation/warehouse_documentation/render.R topo.Rmd
```

To render without opening the PDF automatically, add `--no-open`:

```sh
Rscript render.R topo.Rmd --no-open
Rscript documentation/warehouse_documentation/render.R topo.Rmd --no-open
```

To let preliminary checks install missing R or TinyTeX dependencies from the
terminal, add `--install`:

```sh
Rscript render.R 2 --install
Rscript documentation/warehouse_documentation/render.R 2 --install
```

Temporary LaTeX files are deleted after successful renders. If a render fails,
they are kept for debugging, and the script will advise running preliminary
checks before trying again. After fixing a render issue, rerun through
`render.R`; do not compile kept `.tex` or `_render_*.Rmd` files directly because
they may contain stale generated paths.
